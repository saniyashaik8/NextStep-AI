# NextStep-AI - AI Career Guidance Chatbot

NextStep-AI is an AI-powered career guidance platform that helps students find the right career path based on their skills and interests.

## Features
- Career prediction using ML model
- Personalized course recommendations
- Interactive chatbot UI

## Tech Stack
- Python, Streamlit, Scikit-learn, Pandas

## How to Run
1. pip install -r requirements.txt
2. streamlit run app.py
